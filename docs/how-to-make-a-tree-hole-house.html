How To Make A Tree Hole House

How to make a tree hole house and live in it.

Find A big tree

First, we must find a big tree, the tree trunk's diameter has to be at least 3 meters. If the tree is too small, we can not dig a big enough hole to live inside; if the tree is not big enough, digging a eough hole will kill the tree to die. A huge tree to be digged a one meter diameter hole will not die and also is big eough to be lived in by a man.

Prepare Tools

Prepare tools: many shovels, many saws, many electronic saws, many axes, and even a mountain opener.

These tools must be the best, the sharpest, because a tree is solid enough to be opened.

Prepare many, because if one tool is corrupt, there is another backup.

Start Working

Start working:

Chop the tree near the ground by a sharp axe, chop the tree by a sharp shovel, saw the wood by a sharp saw if necessary. Even shovel the wood of the tree by mountain opener.

Fix Tree Hole

After digging a tree hole initially, the hole is rough, then polish the hole by any small tools, such as axe, shavel.
